# Faeryware V5.1 — Session Colony

Samsung One UI remains HOME. Faeryware is a resident presence layer made of small explicit overlay windows, a reaction capsule, an edge handle, local haunt state and optional narrow context signals.

## Transformed reference patterns

- Assistant-overlay lifecycle: keep one resident session alive across invocations instead of rebuilding a fullscreen dashboard.
- Smart-capsule pattern: context or reaction changes may surface a short-lived compact capsule rather than reopening the app.
- Launcher separation: One UI owns apps, folders, dock, widgets and search; Faeryware owns presence, reactions, perches and haunt state.
- Future optional assistant-role integration is separate from the overlay colony and must remain explicit user choice.

These are architectural patterns only. No third-party branding, artwork or source code is copied into Faeryware.

## V5.1 target

- six Raven-supplied Digi Fae visual anchors
- one draggable resident plus bounded companions
- CALM / HAUNTED / FERAL / APOCALYPSE population levels
- Home-only and Follow-me scope
- persistent session identity and pause/resume semantics
- compact reaction capsule for context/Fae changes
- Ghost House remains the explicit control surface
- no HOME role claim, root, device admin, fullscreen invisible overlay, keylogging or other-app touch interception
