# RavenOS Home

Public mobile shell for RavenOS Home. The live UI is hosted by the already-active public `hurrisonferd/jarvis` GitHub Pages site and consumes only the strict sanitized RavenOS public packet.

## Open it

- **RavenOS Home:** https://hurrisonferd.github.io/jarvis/ravenos-home.html
- **GameBoy mode:** https://hurrisonferd.github.io/jarvis/ravenos-gameboy.html
- **Latest Android release:** https://github.com/hurrisonferd/RavenOS-Home/releases/latest

## Lazy phone path

### Android — easiest

1. Open the RavenOS Home link in Chrome.
2. Use **Install app** / **Add to Home screen** for the PWA.
3. Or open **Latest Android release** and download the `.apk`.
4. If Android asks, allow your browser/file manager to install this one APK from an unknown source, then install it.

The APK opens the live GitHub Pages cockpit when online and falls back to a bundled offline shell when the live page is unavailable.

### iPhone

Open RavenOS Home in Safari → **Share** → **Add to Home Screen**.

## Public boundary

The public UI intentionally does **not** ship private repository paths, transaction IDs, source event IDs, haunt IDs, flight IDs, hashes, receipt bodies, owner-event bodies, Haunt Ledger entries, flight-history rows, tokens, or secrets.
