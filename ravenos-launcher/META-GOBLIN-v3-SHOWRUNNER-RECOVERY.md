## Raven device finding

A Galaxy device can show a healthy Follow-Me overlay and healthy employee rotation while still feeling dead if sensor/setup diagnostics occupy the normal resident text lane. The observed failure was a rotating employee with a persistent line equivalent to:

`Follow-Me is alive · arm Goblin Eye + Goblin Read for visible screen text`

That is useful diagnostics and bad television.

## Settled presentation law

```text
AUTHORIZED READABLE SCREEN
    -> SCREEN mode
    -> observation + contextual truth + deterministic sitcom

NO READABLE SCREEN + REAL PHONE EVENT
    -> PHONE mode
    -> legacy MetaScene / MetaCommentary / character / mayhem stack

NO COMMENT-WORTHY TRUTH
    -> CHIP mode
    -> employee presence only; no fake sentence

EXPLICIT OWNER DIAGNOSTIC
    -> DIAGNOSTIC mode
    -> sensor/setup state may be shown
```

### Important consequences

1. Sensor setup prose is not normal dialogue.
2. Missing Goblin Eye/OCR/Accessibility context cannot permanently occupy OBSERVING mode.
3. Screen meaning still outranks package/window events when screen meaning exists.
4. When screen meaning does not exist, real app/media/notification/home/power events may still earn the older deterministic phone commentary.
5. CHIP silence is valid and preferable to filler.
6. Sitcom casting and dialogue arbitration remain separate: the actor may change while the office stays quiet.
7. Effect authority remains `NONE`.

## S23 technology decision

The current S23 path remains deterministic and local-first:

- Accessibility semantics when explicitly enabled;
- ML Kit Text Recognition v2 for owner-armed Goblin Read;
- screen geometry / OCR fusion in ScreenContextOS;
- MediaSession, notification structure, foreground/window and phone-state facts;
- deterministic callback, narrative, casting and dialogue organs.

Current ML Kit GenAI / Gemini Nano Prompt APIs are **not** a required Goblin Vision dependency. Device support is model/version-specific and the target Galaxy S23 Ultra is not in the current Prompt API support lists. If future hardware/runtime support becomes available, any local generative cortex should remain an optional downstream enhancer rather than replacing deterministic truth/casting/dialogue.

ML Kit OCR supports bundled and Google Play Services-delivered models. RavenOS currently keeps the existing thin Play Services route; a bundled Latin OCR model remains a valid future direct-APK reliability experiment if first-use model delivery proves to be an observed device problem.

## Device canary

The next Galaxy test should prove four independent edges:

1. With Goblin Eye/Read disarmed, Follow-Me returns to CHIP instead of repeating setup text.
2. A real phone event can still earn an old-style employee comment in PHONE mode.
3. After screen reading is armed and readable context arrives, SCREEN mode takes priority and comments on the actual visible subject.
4. Employee casting continues rotating independently of whether the current event earns speech.

Source wiring is not device proof. Promote only after an observed Galaxy pass.
