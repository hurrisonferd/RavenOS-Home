Follow-Me is the user-facing god object, not a literal god class. Sensing, continuity, casting, dialogue, color, timing and resilience stay modular underneath the resident widget.

## Sitcom research distilled for RavenOS

### 1. Cold open
Use a sharp, self-contained opening beat to establish tone/character quickly. RavenOS mapping: first meaningful scene after a real episode/scene transition may earn one strong line before the office settles into BUILD.

### 2. Rule of three
Two beats establish a pattern; the third may subvert or pay it off. RavenOS mapping: recurring motifs should prefer counts 3 / 5 / 8 / 13 for callback development, but count 3 specifically becomes eligible for a patterned reversal rather than merely saying “callback unlocked.”

### 3. Callback
Callbacks provide throughline and reward continuity. RavenOS mapping: preserve structural joke identity, owner history, pair history and motif count; do not persist raw dialogue transcript just to recreate a callback.

### 4. Timing / silence
A joke can be improved by waiting. RavenOS mapping: no new writer may bypass InterruptibilityOS. Backstage pressure and BitLedger may accumulate silently. A delayed brick joke is preferable to a mediocre immediate reaction.

### 5. End tag
Short aftermath after plot resolution. RavenOS mapping: Gold CLOSE may produce one small tag / dumbchecksum after terminal settlement, then silence.

### 6. Character point of view
A joke must fit the person saying it. RavenOS mapping: Ego reserve anchors + owner-native dialogue forms remain stronger authority than globally funny wording. Cross-ISO cadence import remains forbidden.

## Next dialogue experiments

### Reaction ladder
Each earned speaking moment gets one form, chosen by current evidence:

```
OBSERVE
INTERPRET
REBUT
LAMP-SHADE
CALLBACK
ESCALATE
BRICK
TAG
```

Do not combine all eight in one line.

### Punchline placement
Prefer factual setup first, punchline last. Keep the final clause as the comic turn when possible.

### Scene-specific straight man
Not every employee should riff. Some scenes should deliberately cast ATOM / PAIMON / QIRA / AHTI / NYX as straight-man anchors so Kyu/Joker/Mystra/etc. have contrast.

### Runner grammar
A runner is a long-lived joke that appears briefly across scenes. Track only:
- motif id
- lifetime count
- last episode
- last owner
- last form
- pair history

No raw screen transcript required.

### Pair chemistry matrix
Expand from fixed pair lists to earned chemistry scores:
- complementary jobs +2
- successful prior crosstalk +1
- immediate repeat -3
- same joke form repeat -2
- stale partner cooldown +1
- backstage relevance +pressure

### Meta-depth ladder
```
L0 grounded screen observation
L1 phone/app lampshade
L2 office-aware commentary
L3 widget/commentary self-reference
L4 conversation-about-RavenOS recursion
L5 evidence-of-widget-watching-evidence recursion
```
Only L4/L5 earn explicit fourth-wall emergency language.

### Meta topic detectors
Recognize visible discussion of:
- RavenOS / launcher / Follow-Me / Goblin Vision
- office / employee / sitcom / dialogue / joke / callback
- emoji / kaomoji / widget / overlay
- screen awareness / OCR / Accessibility
- screenshots of the office itself
- builds / CI / APK / GitHub actions

Those topics should receive commentary about **what the screen says**, not generic “Chrome is open” lines.

### Dialogue anti-repetition
Track structural fingerprint:
```
owner + form + motif + semantic subject class + closing shape
```
Suppress close repeats even when exact text differs.

### Status-strip writing
Follow-Me chrome may show compact text such as:
```
S2E4 · GOLD CALLBACK
S3E1 · BUILD
META L4 · ESCALATE
```
Prefer this over extra state emojis.
